# Modular UI names Editor

A Switch Homebrew App to create and edit .txt files used by "Modular UI names" patch<br>
<br>
This is still WIP, use on your own risk!<br>
<br>
<br>
Install:<br>
Copy ModularUINamesEditor.nro to SD:/switch/Modular UI names Editor<br>


How to use:<br>
Select an entry, enter your name, press (+) to save the .txt file!<br>
<br>

Use with Controller or Touchscreen.<br>
